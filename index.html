🤔 What Is This?

This is a helper tool for people who use ComfyUI (a program that creates images with artificial intelligence). It works with a special AI model called Qwen-Image-2.1.

Think of it like a smart assistant that takes your simple idea and turns it into a detailed, professional description that the AI understands better. This means you get better, more accurate images every time.

It supports two main things:

  • 📝 Text-to-Image (T2I): You type a description, and the AI creates an image from it.
  • 🖼️ Image Editing: You give it an existing image and instructions, and it modifies the image for you.

🔧 Common Questions & Troubleshooting

❓ Why isn't my image improving?

Make sure you're using the enhanced prompt in ComfyUI. The tool only improves the text description - you still need to use that improved text in your image generation.

❓ Do I need to pay for this?

No! This is completely free and open source. You can use it as much as you want.

❓ Will this work on Mac or Linux?

This version is designed for Windows. For other systems, check the GitHub page for additional versions.

❓ I'm getting an error. What should I do?

First, make sure you have the latest version of ComfyUI installed. Then, check that the Qwen-Image-2.1 model is properly set up. If problems continue, visit the GitHub page and report your issue.
